# VortexLyrics Website

Static website for GitHub Pages.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — settings, language/theme toggles, social links and download link

## Before publishing
Open `script.js` and replace:
- `@1vortex_gd2` with your TikTok username
- `@VortexYT2975` with your YouTube channel handle
- `@VORTEXYTTT2974` with your Telegram channel username
- `MOD_DOWNLOAD_URL` with the direct URL to the mod release when ready

The social icons are already placed in the top-right navigation. Until you replace placeholders, clicking them shows a reminder.

## Publish from a phone
1. Open your GitHub repository `VortexLyrics`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root (not inside a nested folder).
3. Open Settings → Pages.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, then Save.
6. Wait for GitHub Pages to provide the site URL.

No build step is required.
